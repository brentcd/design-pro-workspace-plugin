# Design Pro Workspace plugin

The shareable plugin for Design Pro franchise teams. It sets up, checks and updates a personal Design Pro Workspace: one private page in Claude with your day, jobs, lists and money from Gmail, Calendar, JobTread, meetings and texts, kept current by scheduled updates.

This repository only holds the plugin (no client data and no one's settings). It is laid out as a Claude plugin marketplace: `.claude-plugin/marketplace.json` lists one plugin, in `plugins/design-pro-workspace/`.

**For a franchise's Claude owner:** add this repository as a synced plugin marketplace in your organization's Claude settings, or upload the plugin zip from the install page, and set it to "Installed by default". New versions arrive here on their own.

**For everyone else:** open the Claude desktop app, start a new task and say "Set up my Design Pro Workspace".
